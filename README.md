# 🎵 WAVO – מוזיקה חופשית, בלי תנאים! 🎧

**WAVO** היא אפליקציית מוזיקה מודרנית ורב-פלטפורמתית שנותנת לכם ליהנות ממוזיקה ללא הפסקה, בצורה הכי פשוטה, נקייה ומהירה שיש.

---

## ✨ למה לבחור ב-WAVO?

* 🚫 **בלי פרסומות:** האזנה רצופה ונקייה, בלי הפרעות באמצע השיר.
* 💸 **בלי תשלום:** הכל פתוח וזמין בחינם לגמרי, בלי מנויים ובלי עלויות נסתרות.
* 🔓 **בלי לפתוח חשבון:** נכנסים ומתחילים לשמוע מיד – בלי הרשמה, בלי סיסמאות ובלי למסור פרטים.
* 📱 **זמינה בכל מקום:** עובדת חלק בדפדפן, במחשב השולחני (Desktop) ובמכשירי iOS.
* ⚡ **ממשק מהיר ונוח:** עיצוב מודרני וזורם ששם את המוזיקה במרכז.

---

## 🛠️ טכנולוגיות בפרויקט

* **Frontend:** React, TypeScript, Vite
* **Mobile & Desktop:** Capacitor (iOS), Desktop App
* **Database & Backend:** Drizzle ORM, Supabase
